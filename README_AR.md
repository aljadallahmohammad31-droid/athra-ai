# NASJ / Aetheria Nexus — النسخة الفضائية التجريبية

## التشغيل على Windows
1. فك ضغط الملف بالكامل.
2. تأكد من تثبيت Python 3.10 أو أحدث وإضافته إلى PATH.
3. شغّل `START_NASJ.bat`.
4. سيفتح المتصفح على `http://127.0.0.1:8765`.
5. لإيقاف الموقع أغلق نافذة الطرفية.

يمكن أيضاً فتح `index.html` مباشرة، لكن التشغيل عبر ملف BAT أفضل لتجنب قيود المتصفح.

## ما تتضمنه النسخة
- واجهة فضائية ثلاثية الأبعاد مبنية على Three.js: مجرة النديب، 15 كوكباً/وحدة، وأقمار/مكونات فرعية.
- تنقل هرمي بين الكون والنظام والكواكب والأقمار، مع بحث وتحديد العناصر.
- سيناريوهات عرض تجريبية، مؤشرات أثر، مسارات وروابط مرئية، ولوحة تفاصيل وأدلة.
- رفع ملفات DOCX وPDF وTXT وMD (حتى 15 MB) واستخراج النص محلياً داخل المتصفح.
- تصدير التقرير من نافذة الطباعة في المتصفح (يمكن اختيار Save as PDF).
- نسخة من محرك التحليل التجريبي وملفات المعرفة في مجلد `engine/` للرجوع إليها، وعينة BRD اصطناعية في `assets/`.

## ملاحظات مهمة قبل العرض
- الكواكب والوحدات الخمسة عشر بيانات اصطناعية لتوضيح فكرة المنتج، وليست خريطة مؤكدة للبنية الداخلية لنظام النديب.
- مطابقة المستندات في واجهة 3D لفظية/قائمة على الكلمات المفتاحية، وروابط الأثر غير المباشرة مرشحة وليست حقيقة تشغيلية مؤكدة.
- لا يوجد اتصال بقاعدة بيانات أو نظام إنتاج أو خدمة AI خارجية.
- ملفات DOCX وPDF تُقرأ محلياً في المتصفح. لا ترفع مستندات سرية أو بيانات إنتاجية إلى أي بيئة غير معتمدة.
- يحتاج تحميل مكتبات Three.js وPDF.js وMammoth والخطوط إلى اتصال إنترنت عند فتح الموقع أول مرة.
- PDF المصوّر يحتاج OCR؛ هذه النسخة تستخرج النص الموجود فعلياً في PDF فقط.

## اختصارات
- اسحب المشهد بالفأرة لتدوير الكاميرا، واستخدم عجلة الفأرة للتقريب/الإبعاد.
- اختر كوكباً لفتح طبقته التالية، واستخدم مسار التنقل للرجوع.
- ارفع BRD ثم افتح المكونات المضيئة لمراجعة المطابقات والمقتطفات.

## الملفات
- `index.html`: الموقع الكامل.
- `START_NASJ.bat`: تشغيل محلي على Windows.
- `assets/sample_brd_synthetic.docx`: ملف اختبار اصطناعي.
- `engine/`: ملفات محرك التحليل التجريبي وقاعدة المعرفة السابقة.


## إضافة ATHRA AI (Gemini)
- تمت إضافة مساعد Ask ATHRA AI دون إزالة أو استبدال واجهات التحليل الحالية.
- يتصل المساعد بخدمة Gemini من الخادم المحلي عبر المسار `/ask-ai`، ولا يتم وضع مفتاح API داخل `index.html` أو كود المتصفح.
- يحتاج المساعد إلى اتصال إنترنت ومفتاح Gemini جديد محفوظ في متغير البيئة `GEMINI_API_KEY`.
- على Windows افتح PowerShell في مجلد المشروع ونفّذ:
  ```powershell
  $env:GEMINI_API_KEY = "PASTE_YOUR_NEW_GEMINI_KEY_HERE"
  $env:GEMINI_MODEL = "gemini-2.5-flash"
  .\run_nasj.ps1
  ```
  أو افتح CMD ونفّذ:
  ```bat
  set GEMINI_API_KEY=PASTE_YOUR_NEW_GEMINI_KEY_HERE
  set GEMINI_MODEL=gemini-2.5-flash
  START_NASJ.bat
  ```
- لا تحفظ المفتاح داخل ملفات HTML أو JavaScript أو ملفات المشروع التي ستشاركها. لا ترفع ملفات BRD سرية إلى Gemini إلا بعد موافقة الجهة المالكة واعتماد استخدام الخدمة لهذه البيانات.
- إذا لم يتم ضبط المفتاح، يستمر الموقع وخصائصه السابقة بالعمل، ويعرض المساعد رسالة توضح أن إعداد Gemini مطلوب.
- يحتفظ المساعد بسياق المحادثة في جلسة المتصفح الحالية، ويرسل ملخصاً محدود الحجم عن التحليل الحالي عند السؤال. لا يتم حفظ المحادثات على الخادم.
